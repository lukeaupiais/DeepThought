# Owned declaration calibration fixture

These small Apache-2.0 examples are authored for deterministic harness and
Tree-sitter conformance checks. They cover nested names, repeated method names,
TypeScript interface methods, an arrow function and a namespace. Comment/string
lookalikes are not declarations.

They are **not** a representative application, an independent held-out benchmark,
or evidence of AI-agent performance improvement. Source is read, never executed.
Expected declarations and 1-based start lines are hand-authored in the scenario
pack; the analyzer output is not the grader's reference answer.
